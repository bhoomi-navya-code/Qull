# Qull

A simple note-taking and to-do website

# ⚙️ Technologies

* HTML
* CSS
* JavaScript
* Google Fonts
* Coolors

# 📔 What does it do?

**Qull** is a note-taking and to-do website that I built as my **first project completely on my own**.

With Qull, you can:

* 📝 Create and manage notes
* ✅ Create and manage to-do items
* 🔤 Customize the font
* ☁️ Save and remember notes using cloud storage
* 🎨 Use custom colors and UI styling

# 📚 What I Learned

While building Qull, I learned:

* CSS Flexbox and Grid
* UI management
* Working with HTML, CSS, and JavaScript
* Designing and building a project from scratch
* Solving problems independently
* How to build a complete project without relying on someone else
